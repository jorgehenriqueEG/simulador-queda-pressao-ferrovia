# Simulador Queda Pressao Ferrovia
## Descricao do Problema
Simula a queda de pressao em uma tubulacao de vapor de uma locomotiva durante o freio de emergencia.
## Requisitos
* Calcular a pressao restante apos o tempo de freio.
* Verificar se a pressao minima exigida foi atingida.
## Exemplo de Uso
Entrada: Pressao inicial 8.0 bar, tempo 15s
Saida: Pressao final: 3.2 bar
Status: FREIO INEFICAZ
